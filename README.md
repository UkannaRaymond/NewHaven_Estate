# 🏡 Real Estate Platform

A modern real estate platform built with **Next.js**, designed to make discovering and managing property listings simple and seamless.

## ✨ Features

- 🔐 Secure authentication with **Better Auth**
- 🌐 Google OAuth integration
- 🏠 Create and browse property listings
- 🖼️ Property image uploads with **Cloudinary**
- 📧 Email delivery with **Resend**
- 🗄️ Reliable data storage with **Neon PostgreSQL**
- 📱 Responsive and modern interface

## 🛠️ Built With

**Next.js** · **TypeScript** · **Neon** · **Cloudinary** · **Better Auth** · **Google OAuth** · **Resend**

## 🚀 Getting Started

```bash
pnpm install
pnpm run dev
```

Create a `.env.local` file and add your credentials for:

- Neon
- Cloudinary
- Better Auth
- Google OAuth
- Resend

Then open **http://localhost:3000**.
